Changed in Figma this round

Map tooltips

1b.01m (supplier) and E.01m (ethical team) colour each pin by its Ethical Task Status. Hover a pin for factory, SVSI score, status, valid until, open CAP and scheme; clicking the pin or OPEN TASK opens that task. 1b.01mh and E.01mh show a tooltip open.

Every factory decision has the other options

On registered and subcontracting factory review pages the decision box always offers the other paths: matched → CONFIRM THIS FACTORY / MARK AS NEW / CREATE NEW; marked as new → SELECT EXISTING / CREATE NEW / CONFIRM; created new → MARK AS NEW / CREATE NEW / CONFIRM; confirmed → UNDO / SELECT EXISTING / CREATE NEW (or MARK AS NEW).

Registered and subcontracting factory

Per Sarah, the Ethical flow no longer uses tiers. 1st tier is now Registered Factory and 2nd tier is Subcontracting Factory on every screen, pop-up, tab, chip and button (e.g. ADD SUBCONTRACTING FACTORY). The Type column in Review History shows Registered / Subcontracting.

Switch warning after confirm

Once a factory is confirmed as new (Mark as New or Create New), clicking SELECT EXISTING, CREATE NEW or MARK AS NEW first opens Switch Factory Choice? (3.03w1–w3 for the registered factory, 3.04w1–w3 for the subcontracting factory). It warns that the entered details and temporary code are cleared. CANCEL keeps the choice; SWITCH TO … opens the chosen pop-up. A confirmed existing factory (3.04g) switches without the warning, because no data is lost.

Decision box layout

The confirmed bar reads Confirmed - code (for example Confirmed - F-TEMP-0042), fills the box width and keeps UNDO on the right. Box titles are in title case and centred with their chip. On match cards the match chip sits under the factory name, so long names wrap.

Subcontracting label

The factory chip reads Subcontracting Factory everywhere (no "· New Site").

Supplier statuses

The supplier has its own status names (Supplier sees column). The first is Need to Fill Application (1b.09n, FILL APPLICATION opens the form). 1b.01 Factory List shows one row per supplier status; clicking the status opens that task, not the factory overview. New task pages 1b.09i–1b.09r cover the states that had no supplier page.

Supplier List for the ethical team

E.01 is now the SVSI Supplier List with factories expanded and an Ethical Task Status column; no grey helper text under the status. E.01m is the map view.

Application data on every review page

3.03, 3.04 and 3.05 pages show the supplier's application in a collapsed Application Data block; it opens 3.03x with all sections expanded.

Reasons on both sides

Return (3.03t) and Reject (3.03r) dialogs have a required reason field. The ethical task (E.04 / E.06) and the supplier Application tab both show the reason, who and when.

Supplier Application tab

New supplier pages: 1b.08 Returned → 1b.08e Edit (answers kept, flagged section marked) → 1b.04r Resubmit (Resubmit Reason required) → 1b.08b Resubmitted (read only) → 1b.08c Returned again (round 2), 1b.08r Rejected, 1b.08a Accepted. The lab sees nothing yet.

Save draft everywhere

Leaving any form with unsaved changes opens You Have Unsaved Changes (CANCEL / DISCARD CHANGES / SAVE DRAFT), copied from SVSI. Draft pages: 1b.06d, 1b.08d, E.03d, 3.01b, S.01d, 4.08d, L.03d.

Invoice tab like SVSI

4.12 / 4.13 / 4.14 rebuilt: header with payment status and task status, Inspection Plan table, Other Details, Last Updated, Payer Details. Draft = Pending Invoice, Unpaid = Pending Payment, Paid = Pending Audit.
